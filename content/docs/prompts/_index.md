This section is a library of prompts that you can copy and adapt. Each prompt states when to use it, which interfaces it works in, and which page in this guide explains the context.

## Use a prompt

1. Find the prompt for your task.
2. Copy the prompt with the copy button on the code block.
3. Replace each placeholder in angle brackets, for example `<PROJECT_NAME>`.
4. Read **Adapt it** for changes that you can make for your project.
