This section describes the basic practices that every other section depends on. It explains how Claude uses context, how to prepare a project, and how to configure settings files. It also explains how to write guideline files and how to use skills. The last pages show how to brief Claude on a new project with a seed file and how to run Claude Code in a sandbox. They also show how to use a counter file for requests.
