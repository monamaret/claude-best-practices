This guide describes best practices for using Claude as a coding assistant for software development. It covers Claude Desktop and the Claude Code CLI. When a procedure is different for each interface, the guide shows both in tabs. Select an interface one time, and every page shows the same interface.

## How the guide is organized

The sections start with basic practices and continue to more advanced ones. The last section is a library of prompts that you can copy and adapt. Pages in the other sections link to the prompts that they use.
